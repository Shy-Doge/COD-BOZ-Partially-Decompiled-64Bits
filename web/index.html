Black Ops Zombies · 64-bit Android

Build the APK from your IPA

Everything happens in this browser. Your IPA and the game files are never uploaded anywhere.

Step 1

Choose your IPA

Your own copy of the iOS game, version 1.3.5. About 1 GB.

Advanced patch options

Change these before choosing the IPA. The defaults are the tested ones.

Step 2

Build and save the APK

Needs about 1 GB of free space for the APK. Keep this page open and the screen on until it finishes.

Step 3

Install

  1. Open the downloaded BOZ-64bit.apk and allow installing apps from your browser or file manager if Android asks.
  2. If an older build of this port is installed that was not made on this page with the same key, uninstall it first (Android refuses to update an app signed with a different key).
  3. Start the game and allow the storage permission prompts ("All files access").
  4. The settings file is created on the first start at /sdcard/BlackOpsZombies/config.txt.
Signing key

A signing key is created in this browser the first time you build. Builds made with the same key install as updates and keep your save data.
